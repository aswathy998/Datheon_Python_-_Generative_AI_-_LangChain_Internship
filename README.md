# Datheon Python, Generative AI & LangChain Internship

## Overview
This repository contains Python and Generative AI projects developed as part of the Datheon internship program. The projects demonstrate document processing, structured data extraction, information retrieval, and AI-powered question answering.

## Projects

### 1. AI Document Parser
A Python application that extracts structured information from invoices, validates extracted fields, and saves the results in JSON format.

**Key features**
- Invoice field extraction
- Data validation
- Structured JSON output
- Error handling

### 2. PDF RAG Pipeline
A Retrieval-Augmented Generation (RAG) application that retrieves relevant information from PDF documents and uses a language model to answer questions based on the retrieved content.

**Key features**
- PDF text extraction and document chunking
- Text embeddings and vector-based retrieval
- Relevant source retrieval
- Gemini-powered answer generation
- API quota and error handling

## Technologies
- Python
- Generative AI
- Google Gemini API
- Retrieval-Augmented Generation (RAG)
- PDF processing
- JSON

## Getting Started
1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install the dependencies listed in the relevant project's `requirements.txt`.
4. Configure the required API key using environment variables.
5. Follow the setup instructions in each project's README.

## Security
API keys, environment files containing secrets, and virtual environments are excluded from version control.
